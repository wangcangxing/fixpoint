# 8051 定时器与中断

写定时器代码时遵守这些规则，不要凭印象写：

## 寄存器与位
- 方式寄存器 `TMOD`，控制寄存器 `TCON`；定时器 0 的初值写 `TH0`/`TL0`。
- 中断使能 `IE`（`EA` 总开关、`ET0`/`ET1`/`EX0`/`EX1` 分开关），中断标志 `TF0`/`TF1`。
- 位名都要用 `<reg51.h>` 里已有的名字（`sbit` 定义过的），不要自造寄存器名。

## 初值计算（方式 1，16 位）
```
t = 12 / fosc                      // 一个机器周期
计数 = 65536 - (需要的时间 / t)
TH0 = 计数 >> 8;  TL0 = 计数 & 0xFF;
```
以 12 MHz 为例：机器周期 1 µs，定时 50 ms → 计数 50000 → `TH0 = 0x3C; TL0 = 0xB0;`

## 中断函数写法（C51 方言）
```c
void timer0_isr(void) interrupt 1 using 1
{
    TH0 = 0x3C;      /* 方式 1 必须重装初值 */
    TL0 = 0xB0;
    /* 只做最短的事，不要在这里面 delay() */
}
```
- 中断号固定：外部 0 = 0、定时器 0 = 1、外部 1 = 2、定时器 1 = 3、串口 = 4。
- **方式 1 不自动重装**，必须在 ISR 里重写 `TH0`/`TL0`；方式 2 才自动重装。

## 常见错误
- 忘了 `EA = 1;` 或忘了 `ET0 = 1;` → 中断永远不进。
- 忘了 `TR0 = 1;` → 定时器根本不跑。
- 在 ISR 里调用 `delay()` 或做长循环 → 主循环被饿死（按键/显示都不响应）。
- 中断函数用 `void timer0_isr(void)` 但不写 `interrupt 1` → 编译器当普通函数，中断向量没接上。
