      会生成 <工程名>.uvproj、一个 main.c 骨架，并从你本机的安装里拷一份 STARTUP.A51（不随本程序附带任何厂商文件）。 器件列表读自你本机 Keil 的 UV4.cdb；库里没有的型号（如 STC 系列）请直接用兼容型号（AT89C52）。

      设置

      上下文窗口、thinking、支持图片只是模型目录标注（用于辨认与核对能力，不会进请求）； 输出上限会作为 max_tokens 发送（留空或 0 = 不发送，用提供方自己的上限）； 推理强度按 OpenAI 兼容接口的 reasoning_effort 发送：low / high 原样、max 按 high、off 不发送。

      词元上限默认 0（不限）：不发送 max_tokens，让提供方用它自己的上限——思考模型被小上限卡成"只有思考、没有正文"就是这个原因。 真正防跑飞的是输出字符上限：思考与正文合计超过这个字数就立刻断开上游并结束本轮（0 = 不限）。

      支持任何 OpenAI 兼容端点：DeepSeek https://api.deepseek.com/v1、Ollama http://127.0.0.1:11434/v1、LM Studio http://127.0.0.1:1234/v1、one-api / vLLM 等。 密钥保存在本机 settings.json，不会回显给页面，也不会发给除该端点外的任何地方。

      这几项保存后立即对编辑器生效，并写入 settings.json。

      预设提示词是**外挂文件**：你自己的预设一旦有内容，内置的就完全不参与；内置只在你还没配置、或你的文件读不出来时兜底。 用户级默认在 %APPDATA%\8051 Studio\prompts.json（开发模式是 ~/.keil-ai/prompts.json），工程级在 <工程>/.keil-ide/prompts.json，还可以在下面指定任意路径的自定义文件；同名时后一层覆盖前一层。 每条是 { "name": "…", "description": "…", "text": "…" }，text 就是会填进聊天输入框的提示词。 改完点"保存"，聊天面板的"预设"下拉里立刻能用。
